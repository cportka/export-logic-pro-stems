Logic Pro Stem Exporter

Pull per-track stems out of a Logic Pro project, split overdub takes, rename them, and download a ZIP — all in your browser. For stems with effects & automation baked in, use the one-line macOS companion below.

Drop a .logicx project folder or an audio folder here
Dry audio is read straight from the project's Media/ folder. Files never leave your device.

Wet stems — effects & automation (macOS + Logic Pro)

A browser can't run Logic's Audio Unit plugins, so stems with the channel-strip effects and automation rendered in must be bounced by Logic Pro itself. Run the companion script on your Mac — it drives Logic's Export All Tracks as Audio Files — then drop the output folder back here to rename, split, and ZIP it.

./scripts/bounce-wet-stems.sh --out "~/Desktop/Stems" --format wav --bit-depth 24 "/path/to/Project.logicx"
